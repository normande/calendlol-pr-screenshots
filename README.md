# ReadyWhen PR Screenshot Evidence

This public repository hosts PR-safe screenshot artifacts for ReadyWhen review
comments when private-repository raw links or protected preview URLs cannot be
rendered by GitHub clients.

Only upload screenshots that are intentionally safe for public review. Do not
upload cookies, storage state, raw traces, provider payloads, database URLs,
private calendar details, invitee PII, secrets, or screenshots containing
secret-shaped material.
